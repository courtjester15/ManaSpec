---
name: manaspec-release-validation
description: Verify a ManaSpec React candidate’s builds, generated artifacts, compatibility, or rollback.
---

Follow the [React milestone routine](../../../docs/WORKFLOW.md#react-milestone-build-routine) and [Deployment](../../../docs/DEPLOYMENT.md). Check the stacked PR head and record the exact commit used for release artifacts. Distinguish HTTP review, direct-file portable, and production-origin storage evidence. Treat passing CI as candidate evidence and apply the currently authorized review and promotion boundaries.
